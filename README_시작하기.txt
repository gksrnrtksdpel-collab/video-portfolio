취업용 영상 포트폴리오 · 시작 안내
================================

1) 이 폴더 안의 모든 파일(.pages.yml 포함)을 GitHub의 새 저장소 루트에 업로드하세요.
   주의: Windows에서 .pages.yml은 숨김 파일처럼 보일 수 있습니다.
   GitHub 저장소는 Public으로 시작하는 것이 Pages CMS와 연결하기 편합니다.
   공개 저장소에는 개인정보나 원본 영상 파일을 올리지 마세요.

2) Cloudflare Pages -> 새 프로젝트 -> Git 저장소 연결에서 방금 만든 GitHub 저장소를 선택하세요.
   프로덕션 브랜치: main
   Framework preset: None
   Build command: 비워 두기
   Build output directory: / 또는 . (저장소 루트)
   이후 자동 배포가 활성화됩니다.

3) https://app.pagescms.org/ 접속 -> GitHub 로그인 -> 해당 저장소에 Pages CMS GitHub App 접근 권한 부여
   -> 이 저장소 선택 -> '영상 작품 관리'와 '자기소개 및 연락처'를 수정할 수 있습니다.

4) 922MB 영상은 GitHub에 업로드하지 마세요.
   YouTube에 '일부 공개'로 올리거나 Vimeo에 업로드한 다음 영상의 https 링크를 복사해
   'YouTube 또는 Vimeo 영상 주소' 칸에 입력합니다.
   '사이트에 공개'를 켠 뒤 저장하면 GitHub 커밋 후 Cloudflare Pages가 자동으로 재배포합니다.
   채용 담당자는 웹사이트의 작품 썸네일을 눌러 사이트 안에서 재생합니다.
   유튜브/비메오는 스트리밍 버전을 별도 인코딩하므로 원본을 보존하되 웹 재생은 무손실이 아닙니다.

5) 썸네일 이미지를 업로드하고, 작품명/카테고리/역할/설명을 작성하세요.
   대표 작품(featured)을 켜면 상단에 우선 표시됩니다.
   '사이트에 공개'가 꺼진 기존 4개 항목은 샘플로서 방문자에게 표시되지 않습니다.
   샘플 항목을 실제 작품으로 바꾸거나 삭제해도 됩니다.

6) 자기소개 및 연락처에 지원용 이메일을 입력하세요. 이력서 URL은 선택사항입니다.
   기존 HTML 디자인은 유지되어 있습니다.

파일 구조
  index.html              웹사이트 화면 및 영상 재생
  .pages.yml              Pages CMS 관리자 설정
  data/projects.json      영상 작품 데이터 (관리자에서 수정)
  data/profile.json       자기소개 데이터 (관리자에서 수정)
  media/                  썸네일 이미지 (관리자에서 업로드)

중요한 점
  - HTML 파일을 컴퓨터에서 file:/// 로 더블클릭하면 JSON 데이터를 읽지 못할 수 있습니다.
    Cloudflare Pages에 배포한 https 주소에서 정상 동작을 확인하세요.
  - 웹사이트와 CMS는 아직 사용자의 계정에 배포/연결된 것이 아닙니다.
  - GitHub 저장소에 프로젝트 정보/이미지가 공개될 수 있습니다. 민감한 정보는 넣지 마세요.
  - 공개 가능한 영상만 사용하고 저작권과 공개 권한을 확인하세요.
  - 플랫폼 UI가 업데이트되면 메뉴 이름이 달라질 수 있습니다.
